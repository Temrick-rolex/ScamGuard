Où changer les couleurs

Tout se modifie dans un seul fichier : frontend/lib/core/branding.dart. Aucune couleur n'est écrite en dur ailleurs (vérifié : 0 occurrence).
static const couleurPrincipale = Color(0xFF0B7285); // bleu-vert · barres, boutons static const couleurRisqueFaible = Color(0xFF2F9E44); // vert · score 0-39 static const couleurRisqueSuspect = Color(0xFFE8A317); // orange · score 40-69 static const couleurRisqueDangereux = Color(0xFFC92A2A); // rouge · score 70-100 static const nomApplication = 'ScamGuard'; static const rayonCoins = 12.0;
La classe Textes du même fichier regroupe toutes les phrases affichées : changer un libellé ou traduire l'application se fait au même endroit.
